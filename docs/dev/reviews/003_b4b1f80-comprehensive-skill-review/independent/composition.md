One candidate wording issue:

- **Location:** `references/composition-analysis.md`, **Completion checks**.
- **Exact evidence:** “all four levels are considered when the available material permits it.”
- **Conflicting local cues:** scope permits “selected dimensions within broader work”; procedure 3 says “Inspect the selected levels.” `SKILL.md` also prohibits requiring a full-document audit for a focused edit.
- **Potential consequence:** For a focused paragraph-composition request with a full document available, the completion sentence could be read as requiring additional sentence, section, and document checks simply because material exists.
- **Assessment:** Minor ambiguity, not a confirmed scope violation. “Coverage matches the request” appears in the same completion paragraph, and the entry point and manager repeatedly constrain scope. “Considered” could mean a lightweight relevance decision rather than an audit. Confidence is high that the wording tension exists, but medium-low that it produces consequential behavior.
- **Bounded correction if accepted:** Scope the clause to “the selected levels” or “all relevant levels within the requested coverage.” No broader procedure change is justified.
- **Objective recheck:** Confirm that scope, procedure 3, and completion consistently permit paragraph-only coverage when requested, including when a full document happens to be available. A consumer scenario could assess this later; none was run here.
- **Classification:** Optional precision improvement unless another reviewer establishes actual contradictory behavior. I would not make it an implementation blocker.
